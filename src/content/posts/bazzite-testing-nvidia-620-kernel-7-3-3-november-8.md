Bazzite's **testing-45.20261107.1** release brings **Nvidia Open 620.70.06-1** and **kernel 7.3.3-ogc1.1** to the testing branch. That is the key change from the earlier unstable-only coverage: the newer graphics and kernel stack is now listed in testing images, not just unstable.

## What moved into testing

The release comparison against testing-45.20261107 shows Nvidia Open moving from 615.78.08-1 and the main kernel from 7.2.15-ogc1.1. InputPlumber is listed at **0.84.0-3**. The release was published November 7 at **11:46 AM CST**.

Its commit list includes stronger Valve-hardware warnings (**#6266**), check-anticheat Secure Boot guide/check-order/SM3_256-hint fixes (**#6265**), and Nvidia GPU passthrough for the CoolerControl container. These are descriptions in the project's autogenerated changelog, not independent demonstrations of anticheat compatibility or cooling gains.

## The next testing refresh

**testing-45.20261108**, published November 7 at **8:18 PM CST**, retains the same kernel, Nvidia Open, and InputPlumber versions. Its listed commit removes unnecessary dracut flags (**#6277**). The package table updates **bazzite-updater from 1.2.0-1 to 1.2.1-1**.

Both testing tables list Mesa 26.2.6-2 and Gamescope 3.17.0^1-1. Nvidia LTS remains 580.196.07-1, with its separate kernel at 6.18.60-ogc1.1.

## Unstable context, not a stable announcement

The separate **unstable-45.20261107** comparison explicitly shows InputPlumber moving from 0.83.1-4 to 0.84.0-3; its table also contains kernel 7.3.3 and Nvidia Open 620.70.06.

All three cited images are prereleases. The GitHub release listing checked for this article still identified **45.20261105** as the latest non-prerelease. No stable-channel Nvidia 620 rollout is established by these testing tags, and no measured performance gains are claimed here.
