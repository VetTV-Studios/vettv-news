A community project called Controller Utils can track the 2026 Steam Controller on Valve's Steam Frame. This is an unofficial, experimental app. It is not a Valve release, and its [GitHub README](https://github.com/kallupx/controller-utils) says, "This project is not affiliated with Valve."

The repository is [kallupx/controller-utils](https://github.com/kallupx/controller-utils), described as "Steam Controller tracking and utilities for the Steam Frame." [PC Gamer reported on November 17](https://www.pcgamer.com/hardware/vr-hardware/modder-beats-valve-to-the-punch-adding-steam-controller-tracking-for-the-steam-frame/) that Reddit user Kalluts shared the project on the Steam Frame subreddit, writing, "Valve still has not released their official tracking support for the Steam Controller, so I had to take the matters into my own hands." This article treats the GitHub README as the project's own description, and PC Gamer as contemporaneous coverage of that Reddit post.

## What the README says the app does

The README says the app "Adds support for tracking the 2026 Steam Controller on Steam Frame over Bluetooth." "It uses Frame's native tracking services to track position through the controller's IR LED, and the controller's IMU for orientation." It "displays a 3D controller model in VR." Users "can navigate Steam's UI with a laser pointer or touchpad cursor, and type with both touchpads." "Steam Controller tracking also works while Frame's own controllers are being tracked."

Tracking "relies on a single IR LED." The README says it "can become unstable or drift when the LED is hidden from the headset's cameras," and that "Position tracking recovers when you hold the controller with the LED visible to the headset again."

## Support, limits, and status

"The app supports the latest stable and beta SteamOS releases," the README says. "Since the driver interfaces directly with Frame's native tracking services, SteamOS and SteamVR updates can break tracking and require an app update." The author writes, "I'll try to maintain this at least until Valve releases official tracking support for the Steam Controller." The README also states, plainly: "The app is experimental."

PC Gamer, summarizing the project, reported that the Preview channel "has not yet been tested." The README itself does not mention Preview, and this article does not independently test the app on any SteamOS channel. Valve has not announced a date for official Steam Controller tracking on Steam Frame in the sources cited here.
