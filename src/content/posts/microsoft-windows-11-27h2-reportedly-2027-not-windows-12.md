Microsoft appears to be planning another major Windows 11 release for 2027 rather than introducing Windows 12 next year, according to reporting published November 5.

In his [Notepad column for The Verge](https://www.theverge.com/tech/1027621/where-is-windows-12-notepad), senior correspondent [Tom Warren](https://x.com/tomwarren/status/2118388970379702376) writes that "sources tell me that Microsoft is already preparing for Windows 11 version 27H2." He compares that release to the big **24H2** update in 2024: a "full OS swap, where Microsoft replaces or upgrades major parts of the OS." By contrast, he notes, recent annual releases such as **25H2** and **26H2** have been enablement packages that turn features on after they ship in monthly updates.

Warren also reports a quality focus for that next major Windows 11 release, earlier Insider testing than the usual June window, and a new default wallpaper family that sources say will preview at Microsoft's Ignite conference later this month. **Unconfirmed:** none of those details, including the **27H2** name itself, appear in a Microsoft announcement.

## Earlier Windows Central reporting

Windows Central's Zac Bowden [wrote in late September](https://www.windowscentral.com/microsoft/windows-11/windows-11-version-27h2-faq) that Microsoft had not confirmed plans for version 27H2, but that his sources expected it in the second half of 2027 as the release that brings **26H1** and **26H2** users back onto the same Windows platform. Bowden described it as a full OS upgrade rather than an enablement package, and separately said he did not expect a Windows 12 product in 2026 while the user base is split across two cores.

## What Microsoft has confirmed

Microsoft's own docs do not name 27H2 or rule Windows 12 in or out. What they do say:

- Devices on [Windows 11 version 26H1](https://learn.microsoft.com/en-us/windows/whats-new/windows-11-version-26h1) "won't be able to update to the next annual feature update in the second half of 2026" because 26H1 uses a different Windows core than 24H2, 25H2 and the upcoming feature update. "These devices will have a path to update in a future Windows release."
- Microsoft's [IT Pro Blog post on 26H2](https://techcommunity.microsoft.com/blog/windows-itpro-blog/get-ready-for-windows-11-version-26h2/4529367) repeats that note and frames 26H2 as the H2 2026 feature update on the shared servicing branch with 24H2 and 25H2.
- The Windows Insider Program's [Experimental (Future Platforms)](https://blogs.windows.com/windows-insider/2026/04/10/improving-your-windows-insider-experience/) channel is described as early platform preview work that is "not aligned to a retail version of Windows."

## The Windows 12 question

Warren writes that he "can't answer yet" whether Microsoft will move to Windows 12 branding next year, or whether that is still further out. Bowden likewise says the answer is unknown. Treat "no Windows 12 in 2027" as reporting and analysis, not a Microsoft decision on the record.

*Opinion:* a full platform reunification under Windows 11 would match the awkward 26H1/26H2 split Microsoft has already documented. Until Microsoft names the next release, "27H2" and any Windows 12 timeline remain secondhand.
