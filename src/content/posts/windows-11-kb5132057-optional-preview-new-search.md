Microsoft has released [KB5132057](https://support.microsoft.com/en-us/servicing/os/windows-11/2026/11/kb5132057-windows-11-25h2-26h2-update), an optional, non-security preview update for Windows 11 versions 26H2 and 25H2. Microsoft's support page, dated **November 19, 2026**, and checked at **8:03 a.m. CT on November 20**, lists it as taking 26H2 to OS build **26300.10075** and 25H2 to OS build **26200.10075**. Microsoft's [Windows 11 release information](https://learn.microsoft.com/en-us/windows/release-health/windows11-release-information) page, checked at **8:05 a.m. CT** the same morning, shows the same KB, date and builds as the latest 2026-11 D updates for those versions.

[Windows Central](https://www.windowscentral.com/microsoft/windows-11/windows-11-kb5132057-is-here-with-a-new-search-experience-heres-how-to-get-the-last-update-of-2026) reported the release on November 20 and pointed to a new Windows Search experience as the headline change.

This preview is for PCs already on 26H2 or 25H2. VetTV News covered Microsoft starting to [deliver 26H2 automatically](/posts/windows-11-26h2-automatic-rollout-nov-18/) to more personal PCs beginning November 18.

## The new Windows Search

The new Search experience is part of a gradual rollout, Microsoft says, so it may not show up on every PC as soon as the update is installed. Microsoft also says it is "initially available in English."

In Microsoft's description, the update "introduces a new Windows Search experience with a streamlined design, improved performance, and new ways to complete tasks directly from search":

- Results appear in a single, simplified list, with improved performance and memory efficiency.
- Inline actions let you complete common tasks from Search without opening Settings, such as turning on dark mode or Bluetooth, adjusting brightness, muting the device, or arranging open windows. If an Android phone is connected through Phone Link, you can also call or text contacts or use actions such as "Find my phone" and "Do Not Disturb."
- You can preview files in Search and see details such as when a file was last modified, where it is saved, and who created it, and get quick answers about weather, stocks, and facts. Windows Search also "better recognizes typos and synonyms."

## Other changes in the gradual rollout

Microsoft's highlights for the gradual rollout also include:

- **Windows Hello:** facial recognition can temporarily brighten the screen in a dark or dim room. Microsoft says the setting is under Settings > Accounts > Sign-in options > Facial recognition (Windows Hello), as "Automatically adjust screen brightness during face recognition."
- **Run dialog:** a redesigned Run dialog, turned on under Settings > System > Advanced as "New Run dialog."
- **XBOX mode:** Quick settings on the Gaming Task View navigation bar, so the full set of taskbar Quick settings is available without leaving XBOX mode. That capitalization is Microsoft's.
- **Widgets:** a notification when a newly installed app adds a widget.
- **File Explorer:** search from This PC is now indexer-based, which Microsoft says makes it faster and consistent with search from File Explorer Home.

The same support page lists further gradual changes, including a red screen-capture border, a pointer indicator for low vision, Magnifier and Narrator updates, more control over which audio Live captions transcribe, and web sign-in on Microsoft Entra hybrid joined devices. A "normal rollout" section covers quality fixes, including issues affecting Sage 50 Accounting, Miracast resolution, Android passkeys, and a shutdown warning that could appear even when no one else was signed in.

## How to get it, and December's skipped preview

Microsoft lists the update under Windows Update as optional. The support page's instructions are: open **Start > Settings > Windows Update > Advanced options > Optional updates**, then check for optional updates.

You do not have to install it now. [Windows Central](https://www.windowscentral.com/microsoft/windows-11/windows-11-kb5132057-is-here-with-a-new-search-experience-heres-how-to-get-the-last-update-of-2026) reported that people who would rather wait can let the changes arrive with December's Patch Tuesday. That timing is Windows Central's, not a sentence we found on Microsoft's support page.

Microsoft did say, on the KB5132057 page, "There will be no December 2026 non-security preview update in the second part of the month due to minimal operations during the Western holidays and the upcoming new year." [Windows Central](https://www.windowscentral.com/microsoft/windows-11/windows-11-kb5132057-is-here-with-a-new-search-experience-heres-how-to-get-the-last-update-of-2026) reported that Microsoft's normal update cycle resumes in January 2027.

## Known issue

The KB5132057 page still lists one known issue, and it is the same SQL Server problem we noted in our [26H2 automatic rollout story](/posts/windows-11-26h2-automatic-rollout-nov-18/). After Windows updates released October 13, 2026, and later, SQL Server linked-server connections that use OLE DB providers, including connections to Oracle and PostgreSQL, might stay open on server devices and pile up. Microsoft says it is working on a resolution. This is unlikely to affect a typical home PC.
