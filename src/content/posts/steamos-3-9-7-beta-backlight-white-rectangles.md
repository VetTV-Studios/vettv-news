Valve [posted SteamOS 3.9.7](https://store.steampowered.com/news/app/1675200/view/694278903563288585) on **November 24 at 10:21 p.m. CT**. The notes open by saying, "This update is for the SteamOS Beta and Preview channels, and includes new features that are still being tested." Players can opt in under Settings > System > System Update Channel.

**We are not saying Preview-channel users receive 3.9.7.** Those notes name both channels, but Valve's SteamOS news feed still lists [SteamOS 3.10.1 Preview](/posts/steamos-3-10-1-preview-hotfix-forza-invalid-signal/), posted November 16 at 6:18 p.m. CT, as the latest Preview build. A 3.9.7 package is a step backward from 3.10.x. This story is about the **Beta** channel.

The notes say they "contain all changes since the current stable SteamOS 3.9 release, with the changes added since the previous 3.9 beta releases noted below." Valve's earlier [3.9.6 Beta notes](/posts/steamos-3-9-6-beta-framerate-limiter/) had described changes since stable SteamOS 3.8. We are not treating today's post as a new official stable 3.9 release announcement.

## New in SteamOS 3.9.7

Under **General**, Valve lists:

- "Fixed a rare rendering corruption error that would result in white rectangles appearing on the screen in specific situations"
- "Fixed a 3.9 regression with Steam Deck backlight adjustment behavior"
- "Update timezone definitions"
- Security and stability updates

The backlight item is the one Deck owners who saw odd brightness behavior after moving to the 3.9 beta should care about. Valve does not describe the regression in more detail than that sentence.

The notes then repeat the changes that were new in [SteamOS 3.9.6](/posts/steamos-3-9-6-beta-framerate-limiter/), including framerate-limiter timing, missed frames from deep CPU idle wakeups, games running below the refresh rate on 240 Hz and higher displays, a Remote Play green screen on NVIDIA GPUs, HDR10 SDR oversaturation on displays that are not wide gamut, and a gamescope LD_PRELOAD break, among other 3.9.6 fixes.
