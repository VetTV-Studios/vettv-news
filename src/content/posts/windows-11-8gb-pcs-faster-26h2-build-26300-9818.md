Microsoft says Windows 11 PCs with 8GB of memory are now noticeably quicker. In a November 3 post, Windows chief Pavan Davuluri said Windows is **up to 20% more responsive** on these machines and **multitasking is up to 40% faster** in Microsoft's lab test. Both comparisons are against the January 2026 builds.

## What changed

- **Smarter memory compression.** Windows retuned how much it compresses and when it pages to the drive on 8GB PCs. Microsoft says it can now keep up to 2GB more active data in memory, so apps and tabs you left open are less likely to reload.
- **Priority for what you're doing.** Start, search, right-click menus, Settings, Snipping Tool and File Explorer respond up to 20% faster. Windows backs off background work like search indexing while you're active.
- **Faster Edge launches.** When Edge is already running in the background, Windows connects to it directly. Microsoft says links and Start launches can open up to 33% faster with Edge 150 or later.
- **Lighter apps.** In Microsoft's 8GB multitasking tests, changes across Windows, Edge and Microsoft 365 cut committed memory growth by up to 900MB. Word, PowerPoint, Excel and Outlook account for about 360MB of that. Teams can turn on Efficiency Mode by default on 8GB PCs.
- **Less running in the background.** On PCs with 8GB or less, Widgets now loads only when you open it, which saves about 200MB. Edge now puts inactive tabs to sleep after 15 minutes instead of two hours.

The 40% figure comes from a single lab scenario on an HP OmniBook 3 with a Snapdragon X Plus. Microsoft says it isn't a benchmark and results will vary. Microsoft also still recommends 16GB or more for 3D modeling, advanced video editing and large data work.

## How to get it

You need **Windows 11 version 26H2, build 26300.9818 or later**. Go to **Settings > Windows Update**, turn on **Get the latest updates as soon as they're available**, then select **Check for updates**. Keep Edge, Microsoft 365 and Teams updated too, because some of the gains ship through app updates and the Microsoft Store.

Microsoft says more is on the way, including shared web engines for Search and Widgets and for OneDrive and Photos, and faster WinUI 3 versions of File Explorer, Notepad and Paint.
