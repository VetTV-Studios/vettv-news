[Flathub](https://flathub.org/en/apps/com.epicgames.launcher) is listing an Epic Games Launcher package under the app ID com.epicgames.launcher. The page is marked Unverified. After the usual store description, it says: "This community-provided package is not verified by, affiliated with, or supported by Epic Games, Inc."

Flathub names the application "Epic Games Launcher" and lists the developer as Epic Games, Inc., which describes the software, not the packager. The listing is not a verified Epic app. Appstream data on Flathub gives the packaged launcher version as 0.115.0.

This is an unofficial, community-provided Flatpak. It should not be read as an official Epic Games Linux release.

## What GamingOnLinux reported

[GamingOnLinux reported the Flathub package](https://www.gamingonlinux.com/2026/11/epic-games-launcher-preview-for-linux-now-has-an-unofficial-flathub-package/) on November 16 at 2:05 a.m. CT (8:05 a.m. UTC). It said Epic currently ships an Ubuntu and Debian package, "with plans for more," and that the Flathub listing makes the launcher easier to install on other distributions, including SteamOS. Those packaging claims come from GamingOnLinux, not from an official Epic announcement checked for this article.

In its own test, GamingOnLinux said "I couldn't get it to actually launch Rocket League, but it did launch Absolute Drift just fine," and that there "may be an issue with games that use Easy Anti-Cheat in the Flatpak right now." That is a limited third-party test, not a complete compatibility report, and the Easy Anti-Cheat explanation is not confirmed here.

Separately, the [Bazzite 45.20261115 changelog](https://github.com/ublue-os/bazzite/releases/tag/45.20261115) includes a commit that adds Epic Games Launcher to Bazaar's curated list. That is a Bazzite packaging change, not an official Epic endorsement.
