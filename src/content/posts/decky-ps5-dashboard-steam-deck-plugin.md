Following the Decky Xbox Dashboard plugin we covered on October 31, its developer, GitHub user kromossomom-debug, also has a PlayStation 5-style version. Decky PS5 Dashboard is an unofficial community project under the MIT license. It isn't made or endorsed by Valve or Sony, and it only changes how SteamOS Game Mode looks. It doesn't emulate consoles or add console games, as VideoCardz points out.

## What it does

According to the project's README:

- **PS5-style home:** square tiles along the top, starting with the Steam Store, then your recent games, and ending with the Game Library, with the selected game's key art filling the screen.
- **Info cards under Play:** HowLongToBeat times, your playtime, Steam review score, Metacritic score and install size, and achievement progress.
- **Tabs:** Games and Media tabs, switched with L1 and R1.
- **Game Library:** a tile grid with filters for Playable, Apps, Favorites, Non-Steam and your own collections.
- **PS5 colors across Steam's menus,** with selectable accent colors based on console and DualSense colorways.
- **Languages:** 14 languages that follow Steam's setting, with English for anything else.

The latest release is v1.10.0, published October 31. TechPowerUp notes the developer doesn't describe themselves as a developer and lists Claude as a contributor.

## Installing it

It requires Decky Loader and isn't in the Decky plugin store. Per the README, download ps5-dashboard.zip from the latest GitHub release. Then open Quick Access, go to Decky, open Settings, turn on Developer mode under General, and use Developer > Install plugin from ZIP. The developer says to run only one dashboard theme at a time, so turn off Xbox Dashboard or any home-screen CSS theme first.
